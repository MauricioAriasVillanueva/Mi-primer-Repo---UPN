
# Mis prácticas de programación - UPN

Repositorio dedicado a mis prácticas académicas de Fundamentos de Programación en C#.

## Prácticas desarrolladas

### Tema 6 - Programación modular y reutilización

Sistema de notas desarrollado en C# para practicar:

- Métodos con parámetros y valores de retorno.
- Organización del código en clases y archivos separados.
- Validación de datos.
- Cálculo de promedios y notas máximas.
- Reutilización de métodos.
- Bibliotecas estándar de .NET.
- Documentación XML y pruebas funcionales.

**Archivos principales:**

- `Program.cs`: coordina la ejecución del programa.
- `Calculos.cs`: contiene los métodos reutilizables.
- `Pruebas.md`: documentación de los casos de prueba.

**Ubicación:** `Practicas/Tema-06-SistemaNotas/`

## Tecnologías utilizadas

- C#
- .NET
- Visual Studio Code
- Git y GitHub
